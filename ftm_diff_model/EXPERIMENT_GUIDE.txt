  Feature Tuning Mixup (FTM) - Experiment Guide
  Surrogate: ResNet50 | Images: 50 | Iterations: 300 | Device: CPU
================================================================

----------------------------------------------------------------
 DATASET
----------------------------------------------------------------
Location : data/images/          (50 PNG images)
           data/images.csv       (image metadata)

Details:
  - 25 Tabby Cat images   (ImageNet class 282 → target: 208)
  - 25 Golden Retriever   (ImageNet class 208 → target: 282)
  - Targeted attack: Cat → Dog and Dog → Cat
  - Image size resized to 299×299 during runtime

----------------------------------------------------------------
 FILES WE CREATED / MODIFIED
----------------------------------------------------------------

1. config.py  [MODIFIED]
   - Set max_iterations = 300  (as per paper)
   - Set num_images = 50
   - Set target_model_names to all 15 models from the paper

2. main.py  [MODIFIED]
   - Added image resize transform (299×299) for non-standard images
   - Added torch.nn.functional (softmax) for confidence extraction
   - Added per-image confidence logging (clean + adversarial)
   - Added detailed_results collection per image per model
   - Added CSV export: exp/results/results_summary.csv
   - Added summary export: exp/results/summary.txt
   - CPU-safe: no CUDA dependency

3. evaluate_all_models.py  [NEW FILE]
   - Standalone script to evaluate pre-generated adversarial images
   - Loads adv images from exp/test/adv_imgs/
   - Runs inference on all 15 target models
   - Natural sort for image ordering (cat.1, cat.2 ... cat.25)
   - Saves: exp/results/results_all_15_models.csv
   - Saves: exp/results/summary_all_15_models.txt

NOTE: attacks.py was NOT modified (core attack logic untouched)

----------------------------------------------------------------
 RESULTS LOCATION

exp/

│

----------------------------------------------------------------
 HOW TO RUN
----------------------------------------------------------------

Step 1 — Attack (generates adversarial images + evaluates):
  python main.py --device cpu --batch_size 1 --model_name ResNet50 --eval

Step 2 — Evaluate on all 15 models (uses saved adv images):
  python evaluate_all_models.py
